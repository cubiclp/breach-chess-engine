## 
Breach — UCI Chess Engine

Breach is a free, open-source UCI chess engine written in C. 
It uses bitboardboard representation with magic-bitboard sliding piece attacks, 
alpha-betasearch with iterative deepening, and a persistent transposition table.

This engine is built directly on top of the BBC engine base by Maksim Korzh (Code Monkey King), 
it not merely my own creation. I want to thank Maksim Korzh for the amazing tutorial series and

I estimate the engines strength to be ~2200±50 CCRL Blitz scale.
